# Fontes das imagens — Lander Lan

- Catálogo oficial consultado: https://landerlan.com.br/produtos
- As embalagens utilizadas nesta pasta foram obtidas dos arquivos de produto publicados no catálogo oficial.
- O processamento remove apenas o fundo externo para gerar PNGs transparentes. Marcas-d'água incorporadas às fotos oficiais são preservadas.
- `Proviron 10MG - 20 comprimidos`, `Hemogenin` e `Testoland 6ML - 3 ampolas` não possuíam fotos oficiais com apresentação exatamente correspondente no catálogo consultado e usam imagens ilustrativas no site.
